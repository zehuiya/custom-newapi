# Doubao Seedance 快速配置指南

## 🎯 核心概念

**不是配置最低档价格，而是配置"基准场景"的价格！**

## 📋 各模型应该配置什么价格？

### 1️⃣ doubao-seedance-2-0-260128

```
✅ 配置这个价格：46元/百万token
📌 对应场景：480p/720p + 不含视频输入

为什么？
- 这是一个"中性"场景（既不是最贵也不是最便宜）
- 代码会自动处理：
  ✓ 含视频时打折到 28元（× 0.609）
  ✓ 1080p 时加价到 51元（× 1.109）
  ✓ 1080p+视频时调整到 31元（× 1.109 × 0.609）
```

**渠道配置步骤**：
```
1. 进入后台 → 渠道管理 → Doubao Video
2. 找到模型：doubao-seedance-2-0-260128
3. 设置 ModelRatio = 3.15
   计算公式：46元 × 0.068 ≈ 3.15
```

## 🔢 价格换算公式

```
ModelRatio = 官方价格(元/百万token) × 0.068

原理：
1 USD = 7.3 RMB
系统基准 = $2/1M tokens
换算系数 = 1/(7.3×2) ≈ 0.068
```

|---------|---------|---------|---------|---------|
| 480p 不含视频 | 3.15 | 无 | 3.15 | 46元 ✅ |
| 480p 含视频 | 3.15 | `video_input: 0.609` | 1.92 | 28元 ✅ |

```
场景：1080p + 含视频
基准倍率 = 3.15
自动倍率 = resolution × video_input = 1.109 × 0.609 = 0.675
最终倍率 = 3.15 × 0.675 = 2.13
对应价格 = 2.13 / 0.068 ≈ 31元 ✅
```

```

复制下面的配置值，直接粘贴到对应模型的"模型倍率"字段：

```

## ⚠️ 常见错误

### ❌ 错误 1：配置了最低档价格

```
错误操作：为 seedance-2.0 配置 28元（最低档）

后果：
- 480p不含视频场景会少收费
- 系统无法正确加价到 46元
- 实际价格会偏低
```

**正确做法**：配置 46元（基准场景），让代码自动打折到 28元。

### ❌ 错误 2：配置了最高档价格

```
错误操作：为 seedance-2.0 配置 51元（1080p最高档）

后果：
- 所有场景都会偏贵
- 480p场景会多收费
```

**正确做法**：配置 46元（基准场景），让代码自动加价到 51元。

### ❌ 错误 3：没有理解倍率叠加

```
错误理解：
"1080p + 含视频 = 51元 × 0.609 = 31元"

正确理解：
"1080p + 含视频 = 46元 × 1.109(分辨率) × 0.609(视频) = 31元"
```

## 📞 技术支持

如果配置后发现价格不对，请检查：

1. **ModelRatio 是否配置正确**
   ```sql
   SELECT model, model_ratio FROM channels WHERE type = 'doubao-video';
   ```

2. **日志中的 OtherRatios 是否符合预期**
   ```bash
   tail -f /var/log/app.log | grep other_ratios
   ```

3. **最终计费公式**
   ```
   quota = tokens × ModelRatio × GroupRatio × (OtherRatios乘积)
   ```

## 🎓 总结

- ✅ **配置基准场景的价格**，不是最低档也不是最高档
- ✅ **让代码自动调整**，通过 OtherRatios 实现差异化
- ✅ **验证配置**，确保各种场景的价格都正确
- ✅ **理解倍率叠加**，多个 OtherRatios 会相乘

记住这个核心公式：
```
最终价格 = 基准价格 × (自动调整倍率的乘积)
```
