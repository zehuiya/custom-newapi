# Doubao Seedance 模型计费配置指南

## 概述

Doubao Seedance 系列模型支持差异化计费，根据不同的参数（分辨率、视频输入、音频）应用不同的价格倍率。

## 计费原理

系统采用 **基准倍率 × 差异化倍率** 的方式计费：

1. **管理员配置**：为每个模型设置"基准场景"的 `ModelRatio`（通过后台渠道配置）
2. **系统自动调整**：根据用户实际请求参数，系统自动应用 `OtherRatios` 调整最终价格
3. **最终计费** = `BaseTokens × ModelRatio × GroupRatio × OtherRatios乘积`

**配置方案**：
```
基准场景：480p/720p 不含视频输入
ModelRatio：46 × 0.068 ≈ 3.15 倍率
```

**自动调整规则**：
- ✅ 用户选择 **480p/720p + 不含视频** → 无调整，使用基准倍率 3.15
- 🔽 用户选择 **480p/720p + 含视频** → `video_input = 0.609`，实际倍率 = 3.15 × 0.609 ≈ 1.92（对应 28元）
- 🔼 用户选择 **1080p + 不含视频** → `resolution = 1.109`，实际倍率 = 3.15 × 1.109 ≈ 3.49（对应 51元）
- 🔽🔼 用户选择 **1080p + 含视频** → `resolution × video_input = 1.109 × 0.609`，实际倍率 = 3.15 × 0.675 ≈ 2.13（对应 31元）

## 配置步骤

1. **进入渠道配置页面**
   - 在管理后台找到 Doubao Video 渠道配置

2. **为每个模型配置基准倍率**
   - 参考上述"配置方案"中的 `ModelRatio` 值
   - 在"模型倍率"字段中输入相应的值

3. **验证配置**
   - 系统会自动根据用户请求参数应用差异化倍率
   - 可在日志中查看最终计费的 `OtherRatios`

## 价格换算公式

```
元/百万token → 倍率
倍率 = 价格(元) × 0.068

说明：
- 1 USD = 7.3 RMB
- 1 倍率 = $0.002/1k tokens = $2/1M tokens
- 1 元/1M tokens = (1/7.3) USD/1M tokens = (1/7.3)/2 倍率 ≈ 0.068 倍率
```

## 技术细节

### OtherRatios 命名规范

- `resolution`: 分辨率倍率（1080p 相对于 480p/720p 的加价）
- `video_input`: 视频输入折扣（含视频相对于不含视频的折扣）
- `audio`: 音频折扣（无声相对于有声的折扣）

### 参数提取规则

1. **分辨率**：
   - 优先从 `metadata.resolution` 读取
   - 其次从 `req.Size` 解析（如 "1920x1080"）
   - 默认 "720p"

2. **视频输入**：
   - 检测 `metadata.content` 数组中是否存在 `video_url` 类型的元素

3. **音频**：
   - 从 `metadata.generate_audio` 读取布尔值

## 常见问题

### Q1: 如何验证配置是否生效？

A: 可以在日志文件中搜索 `OtherRatios`，查看系统为不同请求应用的倍率。

### Q2: 为什么有些场景没有 OtherRatios？

A: 当用户请求的参数与基准场景一致时，`OtherRatios` 为空或为 1.0，表示无需调整。

### Q3: 如何处理价格调整？

A: 当官方价格变动时，只需更新渠道配置中的 `ModelRatio` 值，无需修改代码。

### Q4: 系统如何处理多个倍率叠加？

A: 多个 `OtherRatios` 会相乘，例如：
- 基准倍率 = 3.15
- 1080p 倍率 = 1.109
- 视频输入倍率 = 0.609
- 最终倍率 = 3.15 × 1.109 × 0.609 ≈ 2.13
